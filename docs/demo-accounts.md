# 测试账号参考（仅开发/演示环境）

> 本文档仅用于本地开发与演示环境自查。生产环境请勿保留这些口令，上线前务必修改管理员密码。
> 登录页面已不再展示这些账号信息，避免向公网访客暴露默认口令。

## 数据来源

这些账号由后端启动时的 `DevDataInitializer` 在**数据库为空**且 `app.seed-demo-data=true` 时创建（本地 `local` profile 默认开启）：

- 账号密码以 BCrypt 哈希存于 `sys_user.password_hash`，不保存明文；
- 角色绑定在 `sys_user_role`，权限点与角色矩阵每次启动幂等同步；
- 生产环境必须将 `SEED_DEMO_DATA` 设为 `false`。

## 生产环境建议

1. 首次登录后立即在「系统管理 → 用户管理」重置管理员密码。
2. 删除或禁用不需要对外提供的演示账号（`lisi`、`wangwu` 等）。
3. 若线上库是本地库的完整拷贝（含演示账号），请逐个改密后再开放访问。
4. 需要新增账号时，由 HR 先录入员工档案，再由管理员在「用户管理」创建账号并绑定员工与角色（不提供自助注册入口）。
